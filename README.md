# Virtuālā izstāde – tīmekļa vietnes izstrādes projekts

## 1. Projekta apraksts

Projekts ir izstrādāts prakses laikā, izmantojot HTML5, CSS3 un JavaScript.
Projekta mērķis ir izveidot interaktīvu un responsīvu tīmekļa vietni – virtuālu izstādi par izvēlēto tēmu.

**Izstādes tēma:** Videospēļu vēsture
**Izstādes nosaukums:** Pikseļu laikmets

## 4. Izmantotās tehnoloģijas

- **HTML5** – tīmekļa vietnes struktūras izveidei (header, nav, main, section, article, footer).
- **CSS3** – tīmekļa vietnes dizainam, Box Model, Flexbox/Grid un responsīvajam izkārtojumam.
- **JavaScript** – interaktīvu funkciju un attēlu karuseļa izveidei.
- **GitHub** – projekta failu versiju kontrolei un komandas sadarbībai.

## 5. Tīmekļa vietnes funkcionalitāte

Izstrādātajā tīmekļa vietnē ir:

- Galvene un navigācijas izvēlne (mobilajās ierīcēs – izvēlne ar pogu).
- Hero sadaļa ar aprakstu un pogu uz izstādes saturu.
- Izstādes apraksts (About).
- Attēlu galerija (8 attēli), izmantojot CSS Grid.
- Interaktīvs attēlu karuselis (5 attēli).
- Manuāla (pogas „Iepriekšējais” / „Nākamais”, punkti, tastatūra, pavilkšana) un automātiska attēlu pārslēgšana ar iespēju apturēt un atsākt.
- Responsīvs dizains dažādām ierīcēm (Media Queries).
- Lapas kājene ar informāciju par projekta autoriem.

## 6. Projekta palaišana

1. Lejupielādējiet projekta failus vai klonējiet GitHub repozitoriju.
2. Atveriet projekta mapi.
3. Atveriet failu `index.html` tīmekļa pārlūkprogrammā.
4. Pārbaudiet tīmekļa vietnes funkcionalitāti.
